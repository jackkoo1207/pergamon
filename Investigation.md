# 3. Core technical skills

Their source-of-income skills, layer by layer:

| Layer | What it is | Replaceable? |
|---|---|---|
| Compliance knowledge base | 100+ EU regs (GPSR, CE, EN 82079-1, PPWR, DPP) mapped into 200+ product blueprints | **Hardest to replace** — 20 yrs of Impala experience codified as data. But regs are public: a funded competitor can rebuild in 2–4 yrs |
| Structured content engineering | Regulation-mapped blocks, "controlled, not generative," audit traceability | **Replaceable** — DITA/CCMS vendors (MadCap, Adobe, easyDITA) have done structured authoring for decades |
| AI orchestration / agentic layer | LLM calls, Pergami assistant, planned agent | **Commodity** — any competent team on public LLM APIs |
| Production pipeline | PDF/InDesign/XML export, DTP, 30+ languages | **Replaceable** — standard tooling |
| Tacit domain experience | Keppe/Kazała/Impala know-how | **Hard to copy but lives in ~5 people** — key-person risk |

**Verdict: partially replaceable.** Tech = ordinary SaaS engineering + accumulated data. Moat = data + 20-yr head start + timing (regulatory wave) — a **time-boxed window (2–4 yrs)**, not a wall.

**Threats:**
- Incumbents (Adobe, MadCap, SAP, CCMS players) — they already own the authoring pipeline
- Platforms (Amazon/Temu/OTTO) shipping "auto-generate compliant manual" as a free seller tool → kills the $49/mo long-tail segment
- LLM commoditization — the "ChatGPT can't do it" gap narrows yearly; "controlled, not generative" is a hedge against this

**Job angle:** ride the growth window with a plausible acquisition exit (blueprint data + customers are the asset). Don't expect a decade-long technical moat.

**Interview question:** *"What's your blueprint count growth per quarter, and what stops Amazon from shipping this as a free seller tool?"*

# 4. The company next step
According to interview bewteen CEO and CTO, they want to shift Pergamon to Agent AI-based.

Originally, Pergamon relies on filling in questionaire. Now, the company wants to have an AI agent that can search for information by themselves directly, e.g. input current techinal documentation, find current gap and prompts user if it has mismatch with EU regulations to ask for further information, or email the related department directly if information is not sufficient
